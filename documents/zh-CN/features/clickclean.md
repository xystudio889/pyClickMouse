# ClickClean

ClickClean是clickmouse的精简版，移除了以下内容：

- 大部分设置，剩余热键、连点器和小部分基础设置
- 连点属性查看和快速连点设置
- 清理缓存
- 更新
- 扩展功能
- 安装、卸载助手

并且：
- 轻便快捷：安装包大幅缩小
- 无需安装，开箱即用
